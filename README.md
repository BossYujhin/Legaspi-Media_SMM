# Legaspi Media Luxury SMM Agency Website

A market-ready React + Vite website for a luxury social media marketing agency. The design is based on the provided Legaspi Media mockup, improved with better readability, stronger conversion sections, premium spacing, and responsive layouts.

## Run locally

```bash
npm install
npm run dev
```

## Build for production

```bash
npm run build
```

## Project structure

```text
src/
  components/
  data/
  pages/
  App.jsx
  main.jsx
  styles.css
public/
  images/
```

## Pages

- Home
- About
- Services
- Portfolio
- Process
- Pricing
- Contact
